Mục tiêu: Giảm thời gian dò file, giữ nguyên việc tự làm

  • Phần trợ lý gánh giúp: Đọc cùng lúc các file hướng dẫn và mã khung, chỉ đúng file:dòng và báo ngay nếu hai file ghi khác nhau.
  • Phần học viên tự làm: Nắm rõ vì sao bài lab cần bước đó, tự cài môi trường, tự viết/sửa code và tự chạy lệnh kiểm thử trên máy.

Khác gì dùng trực tiếp Claude Code / Cursor / ChatGPT?

  • Coding Agent ưu tiên ra code nhanh: Thường viết luôn lời giải hoặc tạo file outputs/*.json. Nghiên cứu của Bastani et al. (PNAS 2025) cho thấy AI làm hộ làm điểm tự làm khi bỏ công cụ giảm 17%.
  • Quy tắc không tắt được: Học viên dễ tắt Study Mode hoặc xoá CLAUDE.md lúc sát hạn nộp; Lab Compass kiểm tra ngay ở luồng code hệ thống.

Bước 1 · Tách tín hiệu Đọc chế độ (/1, /2, /3) & đường dẫn /repo. Nhận diện câu hỏi gỡ lỗi, câu thiếu ngày lab, nhờ làm hộ hoặc nhờ cài môi trường/chạy lệnh.
Bước 2 · Công cụ chỉ đọc scan_lab_codebase đọc cây .md/.py (bỏ qua .env) & search_docs tra BM25, tự kéo kèm mục đối chiếu (conflicts_with). 0 token.
Bước 3 · Gọi Model 1 lần claude-haiku-5-5 nhận dữ liệu bọc thẻ XML, trả JSON theo 5 nhánh và giải thích vì sao cần bước đó khớp mức người học đã chọn.
Bước 4 · Bộ lọc đầu ra (1) Xoá khối code Python/JSON/YAML lời giải; (2) Chỉ giữ mã nguồn thuộc đoạn vừa đọc; (3) Kèm draft_coach_question khi lệch file hoặc thiếu nguồn.

/1 · Giải thích (giai_thich)

Giải thích vai trò các file trong bài lab và vì sao bài lab đặt ra quy định hoặc bước làm đó (dựa trên nguồn đọc được, không suy diễn thêm).

/2 · Gợi ý (goi_y · Mặc định)

Chỉ đúng [mã mục] (file:dòng), nêu điều kiện đạt và đặt 1 câu hỏi gợi mở để người học tự suy ra bước làm hoặc tự khoanh vùng lỗi.

/3 · Cầm tay chỉ việc (cam_tay)

Chia thành các bước tuần tự + hỗ trợ gỡ lỗi 3 ý (nguyên nhân gốc → file:dòng → lệnh tự kiểm). Không viết trọn hàm, không chạy lệnh hộ.
